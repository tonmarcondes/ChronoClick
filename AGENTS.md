# Como trabalhar neste projeto

- Escreva commits em português, com frases naturais e diretas, próximas do jeito de escrever do dono do projeto. Exemplo: `Corrige os cronocliques e evita repetir a entrada no mesmo site`.
- Mantenha o README e os textos da interface nesse mesmo tom. Explique o que mudou sem frases promocionais ou jargão desnecessário.
- Antes de fazer push, rode os testes e confira se não há gravações, prints, documentos pessoais ou segredos entre os arquivos enviados.
- Não apresente uma captura incompleta como completa. Preserve os avisos e a confirmação para exportação parcial.
